# 一键启动

Windows 启动：

```powershell
.\start.ps1
```

或双击：

```text
start.bat
```

Windows 停止：

```powershell
.\stop.ps1
```

Linux / macOS 启动：

```bash
./scripts/bootstrap_venv.sh
./scripts/dev.sh
```

Linux / macOS 停止：

```bash
./scripts/stop-dev.sh
```

Vercel 发布：

```powershell
vercel.cmd deploy --prod --yes
```
